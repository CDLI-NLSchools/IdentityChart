# Identity Chart

A single-file chart builder for Grade 8 STEAM, Body, Mind and Soul, Lesson 14: Identity Chart. It replaces a Jamboard activity that no longer works.

Students put their name at the top and fill in nine boxes, the same nine categories as the class chart:

- Biology
- Background
- Family
- Friends
- Personality
- Experiences
- Dreams/Goals
- Hobbies/Interests
- Media

Each box holds as many short entries as the student wants to add, with an example in the style of the worked example chart to get them started. When they are done, the app compiles their entries into one printable identity chart, laid out as a grid of boxes, that they can print or copy into their portfolio.

Formative only: nothing is scored, nothing is submitted anywhere, and nothing leaves the student's browser. Single HTML file, no external resources, works offline.
